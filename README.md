**English** · [中文](#中文)

Backend engineer working with Node.js and PostgreSQL, currently on a SaaS for clinics. The side projects here are mostly about self-hosting, local LLMs and real-time tools.

**Things I've built**

- [CommuCloud](https://github.com/jeje898281/commucloud) — runs a condominium owners' meeting: QR check-in, QR ballots, and a live count of whether the meeting has reached quorum by headcount and by floor area. Express, PostgreSQL, Redis, React.
- [StreamGloss](https://github.com/jeje898281/StreamGloss) — live Traditional Chinese subtitles for English streams, running entirely on my own machine with Whisper and a local LLM. Python, faster-whisper, Ollama.
- [PTT Danmaku](https://github.com/jeje898281/ptt-danmaku) — scrolls new comments from PTT threads across the screen while you watch a stream, using the same long-polling feed as PTT's web client, with no login. Electron, macOS and Windows builds.

**Other experiments**

- A spaced-repetition vocabulary app that imports Anki decks and runs as a PWA on the phone.
- A LINE group bot that answers questions about a shared trip from a verified itinerary, on Cloudflare Workers.
